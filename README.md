# BreezeCalendar

✨ 轻量、美观、易用的在线日历 Web 应用 ✨

## 🔗 在线访问
- 主站：https://breezecalendar.zosierly.com/

## 🎯 核心功能
- 📅 多视图切换：日/周/月/年视图自由切换，适配不同使用场景
- 📱 响应式设计：适配电脑、平板、手机等多终端设备
- 🎨 简约UI：清爽视觉风格，无冗余信息，专注核心体验
